تطبيق مولّد أكواد التاجر الذكي (PWA)
====================================

محتويات الحزمة:
- index.html : واجهة المولّد ودالة توليد الكود من معرّف الجهاز.
- manifest.json : إعدادات التطبيق التقدمي (PWA).
- sw.js : ملف التخزين المؤقت للعمل دون اتصال بالإنترنت.
- icon.svg : أيقونة التطبيق.

خطوات الاستخدام والنشر:
1. ارفع هذه الملفات إلى مستودع جديد على GitHub وفعّل GitHub Pages.
2. إذا أردت توليد APK عبر PWABuilder، يُستحسن توفير أيقونة بصيغة PNG بمقاس 192x192 وتحديث manifest.json لتشير إليها بنوع image/png.
3. تأكد من مطابقة SECRET_SALT مع منطق التحقق داخل نظام التاجر الذكي.
